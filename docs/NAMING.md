# Names for public games

The authored adaptations should use their own names before a public firmware launch. The display names are Bitty Flap, Bitty Swarm and Bitty Breaker. Bitty Jet, Bitty Buddy and Hockey Queen already identify this project's adaptations. No trademark clearance of these names has been completed.

An imported cartridge can retain its actual title so the user can identify their own file. Mario, Tetris and Geometry Dash entries describe local cartridge integrations. Their titles do not imply that the project distributes those games or has their publishers' endorsement.

Names and artwork have separate concerns. The [U.S. Copyright Office's games guidance](https://www.copyright.gov/register/tx-games.html) distinguishes game ideas and methods from protected expression such as artwork. The [USPTO's guidance on confusion](https://www.uspto.gov/trademarks/search/likelihood-confusion) explains why similar branding on related goods needs a separate review. Authored graphics and a new name help establish the project's identity. They do not provide blanket clearance for a game's overall presentation or imported files.

Public source and authored firmware exclude commercial ROMs, APKs, extracted artwork and reference-game audio. Import tools operate on the user's lawful local files. A rights acknowledgement records the user's confirmation; it does not grant them a license or replace the underlying permission.
