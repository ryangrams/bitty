# Reference audit lessons

Jetpack: separate native world units, meters, screen pixels, fixed simulation ticks and bonus-local clocks. Coin pattern width contributes to the next spawn cursor. Measuring the right edge of every live pattern can accidentally include an earlier formation. Vertical fitting that changes cell pitch alters both artwork and course spacing. Source coin templates have blank entries as well as populated ones. Preserve their scheduled spans.

Vehicles: test tap and hold semantics individually. A gravity switch, additive bird flap, buffered ground jump, teleport marker and shielded robot are distinct integrators. Coins must stay collectible during boosts and special sequences. A magnet should move a coin and credit it on contact, preserving value if its bounded animation pool fills.

Mario: compare optimized crop/idle batching with a full-video baseline over moving-platform scenes. A previous 6,000-frame private NTSC probe matched every RAM byte and displayed pixel between those paths and matched sampled platform trajectories with JSNES. The camera still jittered because its target came from animation pixels. Keep stable body coordinates and visibility independent. These results describe that build and scenario, not every cartridge or later change.

Bonuses: retain source event order, clock domain, wave bounds, weighted selection and transition conditions. State deliberate adaptation of odds or limited storage. Do not market approximate finite reels as exact original odds.

Use synthetic source-only fixtures for publication. Keep private ROM scene setup, extracted pattern data and APK disassembly outside the source manifest.
