01 / FIRST TIME HERE?

Plug in. Put Bitty on it.

Use a data-capable USB cable and a desktop browser with Web Serial. Check the model printed on your case before installing.

This build supports the original M5StickC Plus, ESP32, 4 MB. Plus2, StickC, Core and S3 boards need their own tested builds.

Install Bitty

Development preview. The new USB library is awaiting its first complete hardware installation and transfer check. Read the release status before installing.

First installation may erase the device. Routine app updates can preserve the library. Close the USB library connection before using the installer.

02 / MAKE ROOM FOR A FAVORITE

Your Stick. Your library.

Cartridges go from this browser to your M5 over USB. The site never uploads your files.

Not connected. Connecting ends the current run and opens the USB library.

Flash space used
Connect to see the cartridges stored on your Stick.

Add a cartridge

Bring an NTSC .nes file you have the rights to use. NES mappers 0, 1, 4, 37 and 118 are supported, up to 1 MiB. Specialized Tetris and Geometry adapters require a supported prepared cartridge.

This acknowledgement does not grant rights. Bitty includes project-created starter art and code. Commercial ROMs, APKs, music and original game artwork are supplied by you.

Removing a cartridge recovers its storage space. Built-in game engines are part of the firmware. Add or remove those through a firmware build. Native code is not installed through the cartridge uploader.
